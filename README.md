# CRM113 - Incident detection with SIEM

This project was developed as part of the coursework for the CRM111 and CRM113 modules at [Canadian College of Technology and Business](https://www.canadianctb.ca/). The primary objective of this project is to demonstrate a phishing attack following what happened in September 2025, when npm was used to distribute malware through a popular package.
